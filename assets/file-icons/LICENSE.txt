SFTP name-column icons (`*.png`) are 32×32 association icons extracted from
the local Windows Shell (`SHGetFileInfo`) via `extract_win_icons.py`, so the
list matches Explorer without calling the shell at runtime.

The older `*.svg` files (if still present) are Fluent System Icons:
