SFTP name-column icons use a hybrid set:

1. `*.png` — 32×32 association icons extracted from the local Windows Shell
   (`SHGetFileInfo`) via `extract_win_icons.py`, so familiar desktop types
   match Explorer without calling the shell at runtime.

2. `*.svg` — Fluent System Icons (MIT), used where Windows has no stable
   association (symlink, shell script, source/config, generic file):
   Copyright (c) Microsoft Corporation
   https://github.com/microsoft/fluentui-system-icons/blob/main/LICENSE
