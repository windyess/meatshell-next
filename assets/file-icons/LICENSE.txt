SFTP name-column icons use two bundled layers
(Windows Explorer style preferred):

1. shell/  — Windows Explorer association PNGs (PRIMARY)
             Extracted on Windows via extract_win_icons.py
             (SHGetFileInfo); not queried at runtime.
             Covers folders, Office, media, archives, common
             desktop types, and selected dev associations.

2. fluent/ — Microsoft Fluent File Type Icons (item-types SVG)
             Fills gaps where Shell has no distinct icon
             (Visio, OneNote, Power BI, vector, models, …).
             Source: @fluentui/react-file-type-icons
             https://github.com/microsoft/fluentui
